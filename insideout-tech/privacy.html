What this application is

InsideOut Tech Publisher is a private tool used only by the owner of the InsideOut Tech YouTube channel. It uploads and schedules videos on that channel and reads that channel's own statistics. It is not offered to the public and has no other users.

Google and YouTube data it accesses

The application uses YouTube API Services. With the channel owner's consent, it accesses:

  • the basic information of the owner's own channel (name, ID), to check it is publishing to the right channel;
  • the owner's own videos and their metadata (title, description, tags, publication date, thumbnail), to upload and schedule them;
  • the owner's own channel analytics (views, watch time, retention), to measure how videos perform.

It does not access any other person's account or data.

How the data is used, stored and shared

  • The data is used only for the purposes above.
  • The authorization token is stored on the channel owner's own computer. It is not sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google security settings page.

Google and YouTube policies

By using YouTube API Services, this application is bound by the YouTube Terms of Service and the Google Privacy Policy.
